Bidisha — The kingdom between the pages

Unzip Bidisha-Princess-Day.zip, then run: node server.cjs
Open http://127.0.0.1:4180

The library contains twelve personal books with three passages each.
Click a book spine to select it, then click its cover or Open this little world.
Use arrows, keyboard arrows, or horizontal dragging to browse books.
Scroll vertically past the library to find the paper envelope.
Click the wax seal to unfold the letter. Fold it back to replay the animation.
Sound starts only when enabled. Pause motion and reduced-motion support are included.
Wishes stay in this browser's local storage.

Checks: JavaScript syntax, DOM interaction tests for all twelve books,
chapter changes, book closing, envelope opening/folding/reopening,
and successful HTTP responses for the page and updated scripts/styles.
Visual browser verification has not been completed in this environment.
